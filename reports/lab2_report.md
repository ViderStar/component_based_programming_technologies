## 1. Цель

Реализовать вызов функций, живущих в другом процессе, по протоколу XML-RPC из лекции. Показать Python-клиент и Java-клиент без сторонних библиотек.

## 2. Ход работы

1. Сервер `SimpleXMLRPCServer` на `127.0.0.1:8000`.
2. Зарегистрированы `add`, `mul`, `greet_student`, `inspect_module`, плюс `system.listMethods`.
3. GUI вызывает метод по имени, аргументы разбираются как Python-литералы.
4. `lab2/java/XmlRpcClient.java` собирает XML `methodCall` и делает HTTP POST.
5. CGI из лекции описан в теории и **не реализован**: модуль `cgi` снят в актуальном CPython.

Код: [`lab2/`](../lab2/). Теория: [`labs_info/lab2_theory.md`](../labs_info/lab2_theory.md).

![Окно ЛР2](screenshots/lab2.png)

## 3. Результаты

`python main.py --lab 2` даёт `add(2, 3) = 5`, `mul(6, 7) = 42`, приветствие студента и словарь сигнатур. Тесты `test_add_mul` и `test_inspect` поднимают сервер на порту 18000.

## 4. Выводы

RPC прячет сеть за вызовом метода. XML-RPC удобен для учёбы: протокол текстовый, библиотека уже в Python. Для браузера чаще берут REST; CGI — исторический слой, не стоит тащить в новый код.

## 5. Что смотреть на защите

- старт сервера из GUI и вызов `add`;
- `inspect_module` как мостик к рефлексии;
- исходник Java-клиента, при наличии JDK — кнопка «Java-клиент».
