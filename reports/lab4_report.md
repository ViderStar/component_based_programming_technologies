## 3. Differences from the handout

The handout assumes Java 8; with JDK 17:

- `import javax.swing as swing` and `import java.awt as awt` fail with *No module named …*, while `from javax.swing import JFrame` works. `jcompat.py` calls `sys.add_package` for the Swing packages, after which the handout's imports work.
- A protected method of the Java superclass is called as `self.super__paintComponent(g)`.
- Jython is Python 2.7: `from __future__ import print_function`, `u""` literals for `π`, `-Dfile.encoding=UTF-8`.
- A `JFrame` does not exist in headless mode, so automatic checks use `JPanel`/`JRootPane`; the `JFrame` of the handout is checked in one case that needs a screen.

## 5. Conclusions

Jython makes Java classes ordinary Python names: a Python class can extend `Object`, `JPanel` or `Thread`, a jar is added with `sys.path`, and the reverse direction is a library call to `PythonInterpreter`. The price is Python 2.7 and a dependence on the JDK version: the handout's imports needed a workaround on JDK 17. Keeping the drawing in a `JPanel` and the menu in a `JRootPane` made the GUI part testable without a screen.

## 6. Control questions

1. **What is Jython and how is it run?**  
   Python 2.7 for the JVM. `java -jar jython-standalone-2.7.3.jar script.py`, or an installed `jython` launcher.

2. **How are Java classes used in a Jython program?**  
   `from java.io import File`, then `File("x")`; Java methods, fields, exceptions (`except IOException`) and inheritance (`class MyClass(Object)`) work as in Python.

3. **How to use classes from a jar file?**  
   `sys.path.append("x.jar")` or `-classpath`; then `from com import MyClass`.

4. **How to call Python from Java?**  
   Put the Jython jar on the classpath and use `PythonInterpreter`: `exec("...")`, `set(name, value)`, `get(name, Class)`.

5. **Explain the solution of the laboratory work.**  
   `Canvas.paintComponent` draws the current picture or the sine curve with `Graphics2D`; the menu items share one `ActionListener` that switches the canvas by the action command; a snapshot mode and tests make the result checkable.
